# 全站雾玫红 × 石墨灰主题

在共享主题系统上替换配色，覆盖公开首页、求职者与招聘者工作区、简历展示、消息和管理端。

玫红只承担品牌、主操作、选中标记、焦点和叙事动画连线。大面积使用浅玫灰、白色卡片和石墨灰文字，减少原先深紫色或深色侧栏的视觉重量。

| 用途 | 色值 |
| --- | --- |
| 品牌、主操作 | `#98566b` |
| 悬停强调 | `#7d4155` |
| 选中浅底 | `#f2e7eb` |
| 页面背景 | `#f6f2f3` |
| 正文 | `#30343b` |
| 辅助文字 | `#64616a` |

沿用现有字号、布局与交互。警告、错误和成功状态保留原来的语义颜色，避免把玫红按钮与错误提示混淆；危险操作继续使用红色及明确文案。导航的背景、悬停与选中颜色也纳入 `frontend/src/theme.css`，便于统一调整。

本次只更新本地前端，服务器尚未重新部署。

验证：生产构建和 98 项前端测试通过；岗位契合度在 6 个桌面与手机视口通过；首页 5 个场景、360/390 宽手机布局和减少动态效果通过，无脚本错误或横向溢出。主按钮对比度 5.41:1，正文 12.50:1，辅助文字 5.47:1，选中导航 6.35:1。截图与验证结果位于 `artifacts/rose-theme/`。
