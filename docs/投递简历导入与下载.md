# 投递简历导入与下载

招聘端“简历与初筛”新增“导入投递者简历”，按当前岗位展示仍在授权中的投递。窗口支持搜索、分页、预览、下载和逐份一键导入；重复导入返回已有记录。“应聘与邀请”的授权简历区也提供相同下载和导入入口。

投递附件下载为 UTF-8 TXT（带 BOM），内容是投递时已授权、已隔离联系方式等敏感信息的文本快照。本地文件导入会保留原文件，原文件仅所属账号当前空间可查看、下载；本功能不向企业提供求职者私有原 PDF，也不读取求职者后来修改的私有简历。下载文件脱离平台后无法由站内撤回机制删除。

导入的材料创建企业侧关联记录，保留 source_application_id、application_job_id 和投递版本内容；不访问求职者其他简历、原始文件或 AI 对话，也不加入通用向量索引。删除企业侧材料不改变原投递授权，可以再次导入。

导入材料只用于原投递岗位。新建报告前和模型返回后均复核授权。投递撤回、婉拒、结束、企业或求职者停用、企业认证撤销、岗位监管暂停后，材料不再列出；下载、新分析、旧报告详情、报告列表、审阅、比较导出及关联校准记忆均校验授权。历史数据保留供内部追溯。页面可见时每 15 秒刷新授权状态，回到页面也会刷新。

接口：

- GET /resumes/applicants：已认证企业的授权投递，支持 job_id、q、offset、limit。
- POST /applications/{id}/resume-import：接收 expected_version；原子防重复，只导入服务端投递快照。
- GET /applications/{id}/resume-download：下载本企业仍获授权的投递文本。
- GET /resumes/{id}/download：下载当前身份的有效材料；关联投递仍须有效授权。

验证使用独立合成账号和测试库，不修改已有用户的简历或投递。后端回归涵盖跨账号、CSRF、原岗位约束、并发导入、撤回和模型执行中撤回；前端回归涵盖已导入标记、预览、下载、重复点击及授权失效。
