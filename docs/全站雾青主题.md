# 全站雾青主题

本次只调整视觉配色，保留现有布局、动画、账号入口与业务权限。

面向需要长时间阅读经历和岗位信息的求职者与招聘者，以浅雾绿导航、暖灰页面、白色内容卡片构成阅读层次。青绿色只承担操作与选中状态，大面积深紫底退出界面。

## 色彩与层次

| 用途 | 颜色 |
| --- | --- |
| 主操作、品牌标识 | `#327567` |
| 悬停、强调 | `#285f54` |
| 选中背景 | `#e7f0eb` |
| 页面背景 | `#f3f5f1` |
| 正文 | `#243b37` |
| 辅助文字 | `#536963` |

沿用现有中文字体、字号与间距；不以降低文字透明度来营造柔和感。主按钮白字与背景保持可读对比；次按钮保留描边；禁用操作继续使用灰色、虚线和禁止光标。警告与危险操作保留琥珀和红色。

公开首页仍使用既有固定舞台和连续转场，仅同步卡片、连线、标签与背景的色彩。企业视角由大面积深底改为浅绿底深字。业务侧栏由深底浅字改为浅绿底深字，当前页面使用更明确的绿色底与左侧标记。

所有共享色值集中在 `frontend/src/theme.css`；首页、简历库、AI 工作区和局部组件使用这些变量，避免后续独立维护多套紫色。

核验：前端测试与构建、三种身份的桌面及手机页面、公开首页转场和减少动态效果、主操作及导航文字对比度。

## 验证结果

- 生产构建成功；17 个测试文件、98 项前端测试通过。
- 求职者、招聘者、未认证用户与管理端共 59 次路由及视口检查，无脚本错误、无横向溢出。
- 首页 8 组桌面、手机、横屏和减少动态效果场景通过，真实滚轮转场与反向滚动正常。
- 岗位契合度在 6 个视口通过选择、历史、证据展开等检查。
- 主按钮对比度 5.42:1，正文 11.96:1，辅助文字 5.36:1，当前导航 6.12:1。
- 使用独立合成数据与拦截接口进行验证，未修改真实业务记录，未调用付费模型。

结果保存在 `artifacts/theme-refresh/`；本次更新本地项目，服务器未重新部署。
