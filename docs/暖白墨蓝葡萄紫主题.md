# 暖白、墨蓝与葡萄紫主题

> 历史方案，已由用户确认的[琥珀黄主题与按钮层次](琥珀黄主题与按钮层次.md)替代。

根据用户选择的方案一，全站将大面积紫色替换为暖白与墨蓝，保留葡萄紫作为品牌和主要操作色。共享色值由 `frontend/src/theme.css` 管理，覆盖公开首页、登录与注册、求职者空间、招聘工作区、消息中心、简历库和管理端。

| 用途 | 色值与处理 |
| --- | --- |
| 页面底色 | 暖白 `#f6f5f2`，内容卡片为白色 |
| 导航与正文 | 墨蓝 `#263445`；侧栏文字采用明亮灰蓝 |
| 主操作 | 葡萄紫 `#7556b8`，悬停 `#604397`，小面积浅紫表达选中状态 |
| 次操作 | 白底、墨蓝文字与灰蓝边框；禁用按钮维持灰色虚线和不可用光标 |
| 阅读与说明 | 原文引用、对话气泡使用浅灰蓝；静态技术标签采用中性灰 |
| 表单 | 暖白分区、白色输入区域与明确分割线 |
| 状态 | 成功绿、提醒橙、错误红；修改前后对比中，建议版本以浅绿提示 |
| 首页 | 企业视角使用浅灰绿，收尾场景使用柔和灰绿，并同步转场背景 |

原有布局、滚动转场、交互、认证与业务权限逻辑保持不变。本次仅本地更新，未部署服务器。

## 验证

- 前端 22 个测试文件、120 项测试通过，类型检查及生产构建通过。
- 使用隔离数据库和合成账号，完成 66 项页面及视口检查，覆盖公开入口、两种业务身份和管理端；桌面宽 1440、手机宽 390。未调用外部模型服务。
- 已检查实际页面截图、横向溢出、手机导航、编辑与取消、禁用按钮及文字对比度。
- 主按钮文字对比度 5.56:1，正文与暖白背景 11.61:1，辅助文字 5.22:1，侧栏文字 9.65:1、辅助文字 6.81:1。
- 浏览器验证脚本为 `tests/browser_theme_plan_one.py`，截图与报告位于 `artifacts/theme-warm-ink-grape/`。
- 首页转场回归通过：5 种桌面尺寸、手机纵横屏和减少动态效果模式均正常；检查了真实滚轮的中间帧、反向滚动、最后一幕对齐及登录入口，未出现页面错误或业务写入。
