# 琥珀黄主题与按钮层次

> 历史方案。当前已按用户要求恢复[紫色主题](全站柔紫主题.md)，下方为历史记录。

用户确认采用“琥珀黄、暖炭黑、米白”的设计，并增加按钮的轻微立体感。此方案替代此前的葡萄紫主题，全站使用统一色彩含义。

## 配色与区域

| 用途 | 色值及表现 |
| --- | --- |
| 主色 | 琥珀黄 `#F2C94C`，悬停 `#E9BC37` |
| 黄色上的文字 | 深色 `#302715`，避免黄色配白字；主按钮对比度 9.28:1 |
| 文字强调 | 深金棕 `#6B5117`；与黄色填充分开管理，保证白底上的文字可读 |
| 导航及正文 | 暖炭黑 `#2B2925`；正文 `#302D27` |
| 页面 | 米白 `#F5F3EC`；主对话、内容卡片为白色 |
| 材料区 | 较实的暖灰 `#E8E3D7`，白色材料卡置于其上 |
| 结果区 | 浅暖底 `#F3EFDF`，黄色区域标题与白色依据卡 |
| 状态 | 绿、橙、红仅用于有依据、提醒、错误等小面积状态，同时保留文字 |

两端 AI 工作区共享“材料、对话、核对结果”的区域含义。求职者工作台模式增加栏间间隙与独立边界；手机保持既有单区切换。岗位、简历、投递、报告、偏好、消息与管理页面共用配色，原文引用使用浅暖底。

色值在 `frontend/src/theme.css` 管理；`amber-theme.css` 最后加载，管理分区及操作层次。原有样式中的品牌前景引用改用 `--brand-ink`，填充使用 `--brand`，黄色上的文字使用 `--brand-on`。原先低饱和蓝灰描边、文字与背景同步调整为暖中性色。

## 按钮

- 主按钮：黄色、深字、顶部细高光、3px 底部厚度及柔和投影；悬停抬升 1px，按下下移 2px并收短底部阴影。
- 次按钮和明确的文字操作：白底、清晰描边、2px 底部边缘；悬停与按下反馈比主操作轻。
- 页签、来源说明及状态标签：保持平面，避免所有部件都浮起。
- 禁用：灰底、灰字、虚线，不投影、不位移。
- 键盘焦点保留 3px 外圈；减少动态效果时关闭按钮位移和过渡，保留静态厚度。

仅修改视觉样式及其加载；原有认证、授权、流式输出、简历确认与业务流程不变。未增加依赖，未部署服务器。

## 本次验证

- 22 个前端测试文件、120 项测试通过；类型检查及生产构建通过。
- 隔离合成账号覆盖公开入口、招聘方、求职者、管理端、待认证身份，共 66 项桌面与手机页面检查；无页面错误、横向溢出或外部模型请求。
- 6 个实际操作控件验证默认、悬停、下压、键盘焦点和文字对比度，包括首页主次入口、两种登录、发送、导入；同时验证禁用按钮、三栏底色差异和减少动态效果。
- 首页滚动动画回归覆盖 5 种桌面尺寸、手机纵横屏、减少动态效果、正反向转场及末幕对齐，全部通过。
