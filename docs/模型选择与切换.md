# 模型选择与切换

求职者进入「AI 工作区」，在页面顶部的「AI 模型」下拉框选择模型。选择保存在当前任务中，只影响之后的分析、对话和草稿请求。切换不清空材料、本人补充、历史消息或已有草稿；历史结果保留生成时的模型标记。不同任务、不同账号互不影响，请求处理中不能切换。

默认提供 DeepSeek Flash、DeepSeek Pro、GPT 5.6 Sol（中转站）、GPT 6.1 Sol（中转站）。未配置服务密钥的选项不可选。接口失败会在同一模型重试一次，不会静默改用另一家服务。

## 当前中转验证

2026-10-13 使用本机服务器 `.env` 中的中转密钥查询 `/v1/models`，返回 `gpt-5.6-sol`、`gpt-6-astra`、`gpt-6-sol`、`gpt-6.1-sol`。对 `gpt-6.1-sol` 和 `gpt-5.6-sol` 分别发送合成连接测试，Responses 接口均返回 HTTP 200、completed 状态和有效 JSON。接口接受的名称包含连字符，不能使用截图中的 `gpt-5.6sol`。当前列表未包含 `gpt-5.5`，因此未作为预置选项。

这验证的是中转站接受的模型 ID 和返回内容，不是对其实际底层模型身份的独立认证。测试仅使用合成文本。

2026-10-14 排查 GPT 6.1 Sol 分析失败：中转站分组对非流式请求返回 HTTP 400，错误码 `stream_required`。已启用 `RELAY_RESPONSES_STREAM=true`，并将服务器及配置模板的默认值同步为 true。使用合成简历和合成岗位再次调用实际工作区网关，GPT 6.1 Sol 在约 19 秒内返回 2 项分析、4 条引用，结构与逐字引用校验均通过。未重新发送用户真实简历。

接口认证、访问权限、HTTP 400、限流和超时现在分别显示对应原因；审计仅增加白名单错误码 `stream_required`，不记录服务商原始错误正文。原有完整结果校验与账号隔离仍生效。

## 服务器配置

根目录 `.env` 保存配置，修改后重启后端：

```dotenv
LLM_MODE=live
LLM_DEFAULT_MODEL_ID=deepseek
DEEPSEEK_API_KEY=填写官方密钥
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_PRO_MODEL=deepseek-v4-pro
RELAY_API_KEY=填写中转站密钥
RELAY_BASE_URL=https://api.sourcesdata.com/v1
RELAY_MODEL=gpt-5.6-sol
RELAY_SOL_MODEL=gpt-6.1-sol
RELAY_JSON_MODE=true
RELAY_RESPONSES_STREAM=true
```

旧的 `LLM_MODE=deepseek` 仍可启用全部已配置模型。默认模型用于新任务及原有岗位画像、能力证据流程；工作区的任务切换不会修改服务器默认值。旧任务未保存模型 ID 时，按原有 DeepSeek 任务处理。

DeepSeek 使用 Chat Completions，并显式关闭预置模型的思考模式。中转 GPT 使用 Responses、`store=false`、JSON 输出和输出长度限制，不发送 DeepSeek 专用参数。适配器也支持配置 SSE 流式传输，但前端仍以完整且通过校验的结果呈现。Responses 参数及结构参考 [OpenAI Responses 迁移文档](https://developers.openai.com/api/docs/guides/migrate-to-responses) 和 [结构化输出文档](https://developers.openai.com/api/docs/guides/structured-outputs)。

## 增加其他兼容模型

服务器可配置 `LLM_PROFILES_JSON`，每个配置明确指定接口协议、提供商、模型名和存放密钥的环境变量。模型名和协议须按对应提供商确认，不能假设所有国产服务都兼容。

```dotenv
OTHER_MODEL_KEY=填写该服务密钥
LLM_PROFILES_JSON=[{"id":"other-model","label":"其他模型","provider":"服务商名称","model":"服务商实际模型ID","protocol":"chat_completions","base_url":"https://example.com/v1","api_key_env":"OTHER_MODEL_KEY","json_mode":true,"stream":false,"input_price":0,"output_price":0}]
```

`protocol` 只允许 `chat_completions` 或 `responses`，地址必须是 HTTPS。浏览器只提交服务器允许的模型 ID，不能提交接口地址、密钥或工具参数。密钥不会出现在模型列表、任务结果和审计日志中。

## 数据与费用

模型仅收到当前任务中授权且经过过滤的材料；切换中转模型后，界面提示材料会经由中转服务发送。账号归属、CSRF、任务版本、请求额度及草稿确认校验仍由服务器执行。模型不具有数据库查询、权限变更或执行任意工具的能力。

费用是 token 数乘服务器配置单价的估算，不等于实际账单。中转站和 Pro 单价默认是 0，代表尚未配置，审计中 `price_configured=false`；这不代表免费，基于费用估算的预算也不能限制这些未配置费用。上线前填写相应 `RELAY_*_PRICE_PER_MILLION`、`DEEPSEEK_PRO_*_PRICE_PER_MILLION`，并设置提供商侧额度。现有按账号限制请求次数及并发的保护独立生效。
