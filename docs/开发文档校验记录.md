## 复现

在项目根目录安装隔离的文档构建依赖：

```powershell
npm install --prefix artifacts/development-docs/tools --no-fund --no-audit --ignore-scripts mermaid@11.17.2 marked@16.4.2 mermaid-typora@npm:mermaid@10.6.1
.\.venv\Scripts\python.exe scripts/render_development_docs.py
```

渲染使用开发依赖 Playwright 与本机 Edge/Chrome（或已安装的 Playwright Chromium）；不修改产品依赖。可用 `--browser` 指定浏览器，`--index-only` 只刷新接口索引。

## 2026-10-16：Typora 实体关系图兼容修复

第 6.2 节原图使用未加引号的中文实体名。Mermaid 11.17.2 能解析，但在 10.6.1 中从首个“账号”实体就报词法错误，与用户截图一致。给实体名和关系文字统一加上双引号后，同一关系图在两个版本均解析、渲染成功，无须修改实体关系或升级编辑器。

构建脚本现先在独立浏览器页面用 10.6.1 检查全部 11 图，通过后再用 11.17.2 生成交付 SVG 和 HTML；兼容失败会报告具体图号并终止构建。复现原始错误与修复语法的对照结果保存在 `artifacts/development-docs/typora-reproduction.json`，修复后实体图截图为同目录 `handbook-entities.png`。
