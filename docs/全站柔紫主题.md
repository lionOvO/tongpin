# 全站紫色主题

按用户要求恢复同频的紫色主题，替代琥珀黄方案。保留最近完成的区域分层、按钮立体反馈与岗位底部操作间距。

| 用途 | 色值 |
| --- | --- |
| 主按钮 | `#7356B1`，悬停 `#604597`，白色文字 |
| 强调文字 | `#634597` |
| 侧栏 | 深紫 `#2B2544`，浅紫选中项与深紫文字 |
| 页面 | 浅紫灰 `#F3F1F8`，内容及主要阅读区保持白色 |
| 材料与结果 | 材料浅紫灰 `#E9E5F0`；结果浅紫 `#F3EFF9`，紫色标题栏 |
| 正文 | 石墨灰 `#30343B`；辅助文字 `#64616E` |

共享色值在 `frontend/src/theme.css`，最终区域与按钮样式在 `frontend/src/theme-surfaces.css`。主按钮保留底部厚度，悬停轻抬、按下回落；禁用状态仍为灰色虚线且没有投影。减少动态效果时关闭位移。成功、提醒与错误继续使用各自语义色。

岗位底部操作区与要求卡片保留 24px 间距及分隔线，手机端保留两列按钮。现有首页转场、业务布局、身份认证与授权逻辑不变。本次为本地更新，未部署服务器。

- 6 个实际按钮通过悬停、按下、键盘焦点、禁用与减少动态效果检查；主按钮文字对比度 5.68:1。
