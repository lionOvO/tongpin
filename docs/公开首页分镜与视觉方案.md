# 同频公开首页：固定舞台与五幕叙事

2026-10-16。范围仅公开 `/`；登录、身份认证、角色切换、权限与业务请求继续使用原实现。

## 参考复查与改动方向

重新在 1440×1000 视口检查 https://rxresu.me/，从 0 滚动至 6800px，并记录固定区域的边界与标题位置。其关键是用文档中的滚动距离驱动固定画面内部的变化：Write 场景从约 2400 至 4400px 保留同一位置的纸面和标题；Design 容器长约 360vh，滚动时标题保持在视口约 90px。参考截图与几何记录保存在本机 artifacts/public-home/fixed-reference/。

上一版同频仍是多个纵向区块内部的局部固定与渐入，不能满足“原位切换页面”的要求。这次改成一个统一的固定舞台，五个章节都作为同一视口里的绝对定位图层；原生文档滚动只推进时间线，不把每个章节依次卷过屏幕。

## 视觉与布局

保留紫色 #5C3ED4、深紫正文 #241B3F、次要文字 #665D79、白色纸面与依据绿 #176F62。企业视角的舞台背景过渡为 #29203F。宋体标题、系统黑体正文，无外部字体与动画库。

桌面固定导航高 88px，舞台占据余下视口；左侧为短叙事和操作，右侧为主要演示。底部始终显示合成示例标记、章节编号、总进度和下一幕按钮。资料卡、编辑器与沟通窗口都按该舞台高度排版，操作入口保持完整。

交接改为实际卡片的连续收拢、弧线位移、轻微旋转和展开。根据前后演示容器的真实边界，以 FLIP 变换让旧卡片交给共用纸面，再展开为下一幕的窗口。同一姓名、角色和技术标签在中间态保持关联；身份文字与场景正文错开出现，避免叠字。企业背景随完整转场进度变化。

## 滚动实现与边界

- 使用原生滚动，未阻止 wheel / touchmove，也没有强制滚轮吸附或自动滚到下一幕。
- 一个 track 提供滚动预算，内部 position:fixed 舞台固定，超出叙事区后以合成层位移离场，避免切换定位方式产生布局偏移；五幕长度约为基础单位的 1 / 1.1 / 1.5 / 1.15 / 1.2 倍，AI 幕留出更多阅读距离。基础单位按视口高度限制在 800–1000px。
- 每幕前 66% 推进内部演示并保持稳定，后 34% 进行可逆的纸面转场。约 115ms 的视觉跟随平滑小滚轮步进，远距离导航直接定位，无长时间追赶。静止后停止逐帧调度。
- 缓存 track 和五个演示容器的位置；窗口尺寸、字体就绪、容器 ResizeObserver 变化与人物重播时重测。转场帧只修改 transform、opacity 和必要的 CSS 变量，不逐帧读取布局；纸面变量限定在其自身容器，减少样式传播。组件销毁时清除事件、观察器、定时器和 rAF。
- 非当前章节使用 inert、aria-hidden 和 visibility，避免透明按钮拦截点击或进入键盘焦点。
- 固定舞台关闭 overflow-anchor，流程内容保持独立的固定尺寸区域；避免 sticky 后代在快速点击或聚焦时被浏览器滚到错误位置，叙事区内使用真正的 fixed 定位。离场中的旧演示不响应点击，避免连续操作误推进。
- 宽度不超过 1000px、高度低于 740px 或系统要求减少动态时，取消固定舞台与额外滚动预算，按五幕纵向阅读。手机简化连线，保留手动交互；减少动态时关闭自动汇聚和播放。
- 原有 Home.vue.start、登录 role 参数、企业认证分流及 switchWorkspace 保持原样。

## 收尾页边界修复（2026-10-17）

桌面收尾区最小高度为视口减去 88px 导航高度，内容在该区域垂直居中。这样点击“开始使用”或滚到底时，文档仍有足够滚动距离让固定舞台完整离开；避免旧版收尾区仅约 490px、屏幕较高时舞台底部仍留在约 316px 的情况。

舞台完全退出可视区域后，父级统一设置 inert、aria-hidden 和隐藏样式，排除旧进度条及控件；倒滚回舞台时同步恢复。只通过合成层位移退场，未改变固定定位方式。手机、矮屏和减少动态模式继续采用原纵向布局。


## 第五幕到收尾页的连续转场（2026-10-17）

沿用同频紫色、宋体标题与正文层级，新增“从一次沟通展开下一次相遇”的收尾动作：第五幕保持原阅读区间，最后 34% 的滚动区间用于转场。沟通窗口轻微缩小、旋转并淡出；淡紫色幕布由沟通窗口中心展开至整个舞台，小标题、大标题、双入口及说明依次显现。前幕正文退场后才显示新标题，避免字叠字；进度栏同时退场。

收尾页本身就是唯一的可操作 DOM，通过反向位移抵消滚动暂时对齐固定舞台，展开结束时位移归零，自然接回文档流。没有复制一套入口，也没有额外一屏空白滚动。轨道预留高度与脚本一致，避免首次加载的布局变化。向上滚动按同一进度倒放，页面不接管滚轮。控件显现前保持 inert，前幕消失后退出焦点；顶部导航持续可用。

主要形变采用 transform 和 opacity，背景圆角随展开平滑归零。手机、矮屏及系统“减少动态效果”保留纵向静态展示，原登录、角色和权限逻辑不变。
