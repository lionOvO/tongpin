# 同频前端视觉与交互

当前采用[紫色主题](全站柔紫主题.md)。共享色值位于 `frontend/src/theme.css`；最终分区及按钮厚度由最后加载的 `theme-surfaces.css` 管理。权限、资料授权与操作流程保持现有实现；下方带日期的章节保留历史验收记录。

## 视觉规则

- 深紫导航 `#2B2544`、浅紫灰页面 `#F3F1F8`，选中项为浅紫底和深紫文字。
- 主操作 `#7356B1`、白字，悬停 `#604597`；正文 `#30343B`，辅助文字 `#64616E`。
- 白色卡片配明确边框；材料采用浅紫灰底，对话为白底，结果采用紫色标题与浅紫底。成功、提醒、错误保留语义颜色和文字。
- 正文以 14–15px 为主，标签通常为 12–14px；保留正常中文行高和折行。
- 手机保留 AI 分区切换，岗位操作区使用两列按钮；长输入在框内滚动。

## 动态反馈

- 页面标题和步骤卡片轻微进入，步骤间隔 45ms，总进入时间不超过约 410ms。
- 按钮悬停、按下和卡片悬停使用 160ms 反馈；侧栏切换为 220ms；弹窗打开为 200ms。
- 主要操作有轻微底部厚度和阴影，次操作弱一些；状态标签及页签保持平面。禁用按钮没有厚度或位移，减少动态效果时关闭按钮位移。
- 原生展开内容、资料卡业务建议和面试追问轻微出现。提示符仍即时显示文字，不加入等待延迟。
- 不用离场动画阻塞页面导航或表单操作；登录方式仍在原页面的固定区域切换。
- 系统开启 `prefers-reduced-motion: reduce` 后关闭动画和过渡。

AI 输入框为空时按行高确定高度，避免布局切换时占位符测量导致高度膨胀。手机长输入最高 96px，桌面最高 144px，之后在输入框内滚动。

## 验证

使用隔离的合成账号和资料检查工作台、岗位编辑、偏好选择、招聘资料卡、AI 工作台、历史弹窗以及登录方式切换。检查桌面 1440px、平板 1024px、手机 360px 下的布局；截图保存在 `artifacts/visual-refresh/`。前端测试与类型检查、生产构建使用 `npm run test` 和 `npm run build`。


## 2026-10-15：操作与信息的区分

新增 `frontend/src/interaction-system.css`，在页面布局样式后加载，统一全站交互外观：

| 内容 | 常态外观 | 交互反馈 |
| --- | --- | --- |
| 主要操作 | 实心紫色、白字 | 悬停加深；键盘聚焦有外圈 |
| 次要操作、原文字链接 | 明确的实线边框和点击区域 | 悬停底色和边框变化 |
| 删除、撤回授权 | 红色文字、浅红底、边框 | 悬停加深；禁用时仍统一灰色 |
| 禁用操作 | 灰底、灰字、虚线边框 | 禁止光标；不使用透明度淡化整个区域 |
| 来源、版本、说明 | 中性灰蓝文字 | 不套用操作按钮的紫色和边框 |
| 状态、技术标签 | 紧凑平面标记 | 保留状态文字，正常/待处理附圆点 |
| 页签、模式切换 | 未选中为白底框，选中为实心紫色 | 与普通说明文字区分 |
| 可展开内容 | 有边框的摘要行与展开标记 | 展开后保留内容边界 |

阅读区使用浅蓝灰，编辑区使用浅紫分组；各项要求有独立边界，输入框保持白底。岗位、简历、投递、报告、偏好、双方对照、比较、两端 AI、企业认证及管理页共用这套规则。保留现有动画与减少动态效果设置。

岗位页面不再默认铺开已确认画像的编辑表单。`JobRequirements.vue` 展示技术方向、学历和逐项原文；招聘方通过“编辑岗位要求”进入编辑区，取消恢复已保存内容，确认保存生成新版本后回到阅读态。未确认的岗位仍直接进入核对表单。“查看此岗位投递”和“设为私有/公开岗位”位于独立操作栏。企业认证材料按“企业登记信息”和“招聘资格材料”分别分组。
