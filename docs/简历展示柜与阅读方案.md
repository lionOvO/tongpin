# 简历展示柜与阅读方案

2026-10-17。参考用户提供的纸张缩略图展示方式，沿用同频紫色品牌，将简历材料列表改为可直接阅读轮廓的展示柜。

## 页面与操作

默认采用卡片视图：浅紫底托承载白色纸张预览，名称、导入日期、字数和来源置于纸张下方。操作与信息分层：AI 完善为紫色主要操作，查看依据为次级操作，下载与删除保持独立且始终可见。工具栏提供名称搜索、导入时间或名称排序以及卡片/列表切换；只在本机保存视图偏好，不保存简历正文。

点击纸张或标题进入放大阅读。新上传的 PDF 以原文件渲染缩略图，默认打开“原 PDF”，保留字体、配色、图片和原版布局；多页文件提供翻页。“文本排版”和“分析文本”另外呈现提取、隔离敏感信息后的正文，分析文本页可下载 TXT。招聘端另有初筛依据页签。窄屏改为单列卡片和接近全屏的阅读窗口。

文件导入同时保存原始字节和现有分析文本；`GET /resumes/{id}/original` 仅对材料所属账号当前空间开放，返回 `no-store`，物理文件路径不对外公开。招聘端从投递导入的仍是已授权文本快照，不继承求职者私有原文件。手动编辑或 AI 采纳产生新正文版本，不把旧 PDF 冒充为新版本。原文件仅存在于原导入记录中。

旧版导入未存原文件，无法从提取文字中恢复原样式；阅读窗口解释原因并提供重新上传入口。粘贴文字和没有原文件的材料仍可按文本阅读，普通连续行不额外增加段落间距。现有文本下载接口保持兼容。

PDF.js 动态加载，卡片进入视口附近才读取文件；一次渲染一页，像素数量有上限，关闭窗口时取消请求与渲染并释放文档。字体、CMap、图像解码器与 Worker 随前端本地打包，无外部 PDF 服务；预览通过带当前标签页会话头的请求获取字节，不使用公开文件 URL 或执行 PDF 内链接、表单、脚本。

## 保留的功能

- 求职端：文件/文字导入、AI 完善、查看依据、下载、删除及删除确认。
- 招聘端：已授权投递导入、本地导入、当前岗位范围、初筛整理、依据阅读、勾选分析、能力报告生成、下载和删除。
- 原账号、企业认证、角色权限、授权撤回刷新与历史记录保留逻辑不变。正文使用 Vue 文本插值呈现，不执行导入内容。
