# 首页：双向相遇

采用用户选定的现代人物双门插画（exec-7b92daf1-f869-459d-83e3-7da25a0978b8.png）。这张图表达双方各自打开空间、在相同高度走向彼此；本次没有采用后续的古装概念图。

## 页面布局

- 首屏保留左侧标题、身份入口、授权说明，以及三个人物的合成资料示例。
- 右侧默认展示相遇插画。通过“双向相遇 / 个人资料演示”切换原有资料卡；点击合成人物也会进入资料演示。
- 插画下方分别说明求职者带来经历与期待，招聘者带来岗位与诚意。插画是品牌隐喻，不代表真实用户或投递结果。
- 手机端改为纵向，保留完整画面，不通过裁掉一方来适配窄屏。

## 动画

- 使用同一张图的左右裁切图层，以小幅平移汇合；随后以 SVG 路径描画双方的连接。不对生成图进行伪造骨骼或门轴运动。
- 桌面端复用原有约两秒的 `--gather` 入场与重播进度；滚动时由原有固定舞台承载整个视觉区域，折叠转入岗位场景。
- 手机端使用一次性 CSS 入场，无滚轮接管或常驻计时器。
- 系统减少动态效果时直接展示静态终态，手动切换仍可用。
- 桌面可用视口宽度超过 1000px、高度达到 640px 时保留固定舞台与滚动转场；640–739px 高度采用紧凑间距，不整体缩小文字。更窄或更矮的窗口改为自然长页。浏览器缩放通过改变可用视口影响布局，不按缩放百分比关闭动画。

## 资源与边界

- `frontend/src/assets/tongpin-mutual-doors.webp`：原图比例，约 155 KB。
- `frontend/src/assets/tongpin-mutual-doors-small.webp`：960px 宽版本，约 41 KB。
- 使用本地资源和响应式图片，不依赖外部图片服务。浏览器会缓存重复图层共用的图片请求。
- 登录入口、身份认证、企业权限、后续岗位 / AI / 企业阅读 / 沟通流程保持现有逻辑。
